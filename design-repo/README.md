# Cradle design-repo

A machine-validated PageSpec system for the Cradle marketing site (a real company's public website). A generator composes pages from 98 section contracts, 26 templates and 101 routes without inventing colours, copy budgets, sections or assets.

It serves two uses, selected per PageSpec by `mode`:

- **`generation` (the default; used when `mode` is absent)**: new pages for the AI team (Common v0.5 IR, RAG/Remix). Only generation-safe asset roles (placeholders or newly generated original art, never an `assetRef`), style values only as catalog token references, and no Cradle brand, customer, people or proprietary content.
- **`clone`** (opt-in with `"mode": "clone"`): exact reproduction of the local clone for fidelity QA. Clone-only roles with their registered Cradle files are allowed here and nowhere else. Everything here is derived from the local clone (`src/`, `CLONE_SPEC.md`, `ia.json`), not guessed.

Status: **design-review-pending**, `productionApproved: false`.

## Layout

- `tokens/00-foundation` colour, typography, radius, spacing, breakpoint, elevation, icon-size, motion. Values come from histograms over `src/` and from `tailwind.config.js` / `CLONE_SPEC.md`; each carries a usage count and a citation.
- `tokens/10-semantic`, `tokens/20-component`, `tokens/30-layout`, `tokens/themes` (light, dark) resolve roles down to foundation values.
- `tokens/llm/token-catalog.json` every usable token (colour, spacing, radius, elevation, typography, motion, breakpoint, sizing, layout, component) with its id, resolved value, category, source file/pointer and evidence citation. Generated by `extraction/build_token_catalog.py`; `verify_all.py` rebuilds it and fails if the committed file differs.
- `tokens/llm/token-policy.json` which categories a PageSpec may reference (colour, elevation, radius, spacing, typography, component presets), the closed list of 17 style fields and the token prefixes each accepts, the single reference form `{"token": "<catalog id>"}`, and the raw-value patterns rejected everywhere (hex, `rgb()`/`rgba()`/`hsl()`, gradients, px/rem lengths, `calc()`, `cubic-bezier()`/ms easing, Tailwind arbitrary-value and palette classes).
- `tokens/llm/component-allowlist.json` closed list of what a generator may use or set, including modes, the clone-only / generation-safe role split and the style fields. `tokens/llm/asset-roles.json` the asset-role registry: contracts, AI-generation guidance and the name denylist.
- `primitives/`, `components/` generic building blocks, each citing the code that implements it.
- `sections/` one contract per section type: content fields with `maxWords`, allowed templates, variants, media roles, motion patterns with reduced-motion fallbacks, and a structured `responsive` block.
- `templates/templates.json` explicit node sequences; `templates/routes.json` every route with its measured navbar/footer variants.
- `compatibility/graph.json` rhythm and structure rules, each `error` or `warn`.
- `schema/pagespec.schema.json` Draft-07 contract; `schema/semantic_validate.py` what the schema cannot express; `schema/tests/adversarial_test.py` proof that each rule rejects a bad instance.
- `extraction/measured-values.json` every citation with an anchor string; `extraction/verify_all.py` the integrity check; `extraction/prove_drift.py` re-runs verify_all on mutated scratch copies to prove each drift check fails when it should.

## Using it

```bash
pip install jsonschema                    # only dependency
python3 extraction/verify_all.py          # full integrity check (includes the adversarial suite)
python3 extraction/prove_drift.py         # proves the drift checks fail on mutated scratch copies
python3 extraction/build_token_catalog.py --write   # after editing any token file
python3 schema/semantic_validate.py my.pagespec.json
```

A PageSpec names a `template`, a `route`, and `nodes` that must equal that template's node list. See `schema/example.pagespec.json`: a generation-mode homepage for the fictional company "Quillfern Bio", with a fictional testimonial (Rowan Vale, Tallowmere Biologics), placeholder logos through the generation-safe `placeholder-logo` role, and token references in every style field. It contains no Cradle copy, customer, person or asset.

Style fields take a token reference, never a raw value:

```json
"bg": { "token": "color.modality.antibody" }
"hover": { "token": "elevation.glow-antibody-8" }
```

## Things that are unusual about this source (read before generating)

- **Source is a real company's live site. Generated pages must never reproduce Cradle's logo, symbol, wordmark or favicons; its customer or partner logos; employee, author or investor photos; real testimonial quotes, names or titles; product UI screenshots, videos, covers or lab photos; or the Cradle name and copy.** This is enforced, not just documented:
  - `tokens/llm/asset-roles.json` splits every role into **clone-only** (12 roles: brand-mark, customer-logo, person-photo, ui-screenshot, lab-photo, editorial-cover, page-image, page-graphic, modality-illustration, video, video-poster, social-image; exact reuse of a registered file, clone mode only, pinned by `verify_all.py`) and **generation-safe** (7 roles: placeholder, placeholder-logo, placeholder-avatar, placeholder-brand-mark, generated-illustration, ui-icon, hero-blob; `generationBrief` required, `assetRef` never allowed). Each clone-only role names its generation substitute, and each section lists its `media.generationRoles`.
  - In generation mode the schema restricts media to generation-safe roles without `assetRef`, and the validator additionally rejects any string naming a registered Cradle file (all 457, including the files observed for ui-icon and hero-blob) and any denylisted name: the brand ("Cradle"), the 12 customers named by the registered customer/testimonial logo files, and the 5 authors whose photo filenames are full names. Matching is whole-word and case-insensitive, so ordinary text containing "cradle" as a word ("cradle-to-grave") is also rejected; link paths and CMS slugs are structural and exempt. Hash-named logo and avatar files carry no name, so they are covered by the role contract rather than the denylist.
  - Section contracts keep the measured source content under `cloneExampleContent`. It is clone reference data (real Cradle copy and filenames), not generation guidance; the generation controls in the adversarial suite neutralise it before use.
- **No outbound links.** The clone renders external anchors as plain buttons and its forms submit nowhere (no `fetch`/`action` in `src/`). The `NO_EXTERNAL_LINKS` rule forbids any URL, `mailto:` or protocol-relative link in a PageSpec; CTA `href`s must be same-site paths.
- **Reduced motion is a generation-time contract, not an observed behaviour.** The source contains no `useReducedMotion` / `prefers-reduced-motion` handling. Every node must still declare a `reducedMotionFallback` mapped to its pattern so that *new* pages degrade safely. All motion is framer-motion JS (no CSS keyframes), so motion patterns are named after the JS behaviour measured in `CLONE_SPEC.md` section 14.
- **Tablet (810-1199px) was not measured on the live site** (CLONE_SPEC section 17). Responsive blocks describe the classes the clone actually uses at `md`/`lg`, not a measured tablet layout.
- **Template nodes are all `required: true, repeatable: false`.** The source shows no optional or repeated section within a template, so none is invented. Two templates (`template.blog-post`, `template.video-post`) cover {53+20} CMS pages; their content is referenced by `{collection, slug}`.
- **16 sections have an empty content contract** (chrome.footer, company.investors, company.open-positions, company.perks, company.photo-mosaic, content.footer-graphic, content.policy-body, content.whitepaper-body, hero.blog, hero.form-page, hero.shirt, hero.whitepaper, product.product-mock, product.ui-collage, proof.case-quote, proof.logo-ticker). Their copy is fixed inside the component or its children, so the contract exposes media and motion only rather than inventing editable fields.
- **Content contracts are derived statically** from literal JSX text, data arrays and component prop signatures; fields are typed at depth 1-2. Word budgets are `max(observed+2, ceil(observed*1.5))` (field `measuredMax` records the observed maximum); where no literal exists the budget is the site-wide observed maximum for that key name (`budgetBasis`).
- **Style is token references only.** There is no free-form override field. The 17 style-bearing content fields found by enumerating every section contract (modality colours, glow shadows, testimonial gradients, logo size, padding, title type and screen-position presets) were raw CSS/Tailwind literals in 1.0.0 and are now `{"token": id}` objects whose ids must exist in the catalog and match the field's allowed prefixes; multi-property presets live in `tokens/20-component` with citations. Numeric collage/choreography parameters (`x`, `y`, `delay`, `travel`, ...) have no token scale; `token-policy.json` lists them explicitly as unitless geometry, not style.
- **Three routes are not in the live sitemap**: `/video` (exists as a page, noted in the IA), and `/legal-terms` and `/privacy-policy` (placeholder pages in the clone whose navbar/footer were not measured on live; `src/chrome.js` styles them like `/dpa`). They are included so every clone route maps to a template.
- A scroll-linked motion budget of 2 nodes per page is the most any real template allows.
- **Known contract weakness, not fixed here:** a few machine-harvested contracts type geometry props as free strings (`hero.case.h`/`kind`, `conversion.form-placeholder.h`, `content.doc-viewer.lines[].x/y/w`). The raw-literal rule rejects unit-bearing values in them, but their shape should be re-derived from source.
