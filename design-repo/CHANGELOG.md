# Changelog

## 1.1.0 (2026-10-13)

Review punch-list pass: token contracts for the Common v0.5 IR, a generation-safe default, and token-only style values. Version goes 1.0.0 -> 1.1.0 (repository, pageSpecVersion and allowlistVersion); the suggested "0.5.0" would have been a downgrade from the shipped 1.0.0, so the IR version is not reused as the repo version.

**A. v0.5 token contracts (were missing).**
- `tokens/llm/token-catalog.json`: 263 tokens (color 77, typography 61, component 42, spacing 22, motion 17, radius 13, elevation 12, layout 9, sizing 8, breakpoint 2), each with id, category, type, resolved value, authored value and references for aliases, `source.file` + `source.pointer` into tokens/00-foundation / 10-semantic / 20-component / 30-layout, and the `measuredFrom` evidence citation. Generated by the new `extraction/build_token_catalog.py`; verify_all rebuilds it and fails on any difference.
- `tokens/llm/token-policy.json`: which categories a PageSpec may reference (color, elevation, radius, spacing, typography, component; not motion, breakpoint, layout or sizing), the single reference form `{"token": "<catalog id>"}`, the closed list of 17 style fields with their categories and allowed prefixes, and the raw-value patterns rejected in every PageSpec string. Its category keys are the catalog's real category names (checked).
- Both registered in `registry.manifest.json` entryPoints (with the builder and `extraction/prove_drift.py`).

**B. Example PageSpec made generation-safe.** `schema/example.pagespec.json` is now an explicit `"mode": "generation"` homepage for the fictional "Quillfern Bio": original copy throughout, a fictional testimonial (Rowan Vale, Head of Protein Science, Tallowmere Biologics) replacing the real Novonesis quote and title, placeholder logos via the generation-safe `placeholder-logo` role replacing the AbbVie customer-logo reference, `placeholder-brand-mark` replacing both Cradle symbol references, and every image/icon content field pointing at a `placeholder:` id instead of a registered Cradle file. Same template (template.home), same 14 nodes and motion, 0 errors.

**C. Clone-only vs generation-safe asset contract; generation is the default.**
- `tokens/llm/asset-roles.json` rewritten: 12 clone-only roles (policy `clone-exact-reuse`, a `sensitivity` and a `generationSubstitute` each) and 7 generation-safe roles (`generate-original` or `placeholder`): the existing placeholder, ui-icon and hero-blob plus new placeholder-logo, placeholder-avatar, placeholder-brand-mark and generated-illustration. The old policies `must-reuse-exact` / `must-not-fabricate` / `may-generate-new` are gone. Adds `defaultMode: "generation"`, `modes`, `aiGenerationGuidance` (explicitly forbids Cradle's logo, customer logos, employee photos, real quotes and attributions, product screenshots and the Cradle name) and `nameDenylist` (brand, 12 customers derived from the registered logo filenames, 5 full-name authors).
- Schema: new optional top-level `mode` (`generation` default, `clone`); a root if/else restricts media to generation-safe roles without `assetRef` unless `mode` is `clone`; each section branch accepts its measured roles plus its `generationRoles`.
- Every section with media now lists `media.generationRoles`. Section `exampleContent` is renamed `cloneExampleContent`, with a `cloneExampleContentNote` in every section file, to mark it as clone reference data (real source copy, e.g. the measured Novonesis testimonial in proof.customers) that must never be copied into generation output.
- Validator: `ASSET_ROLE_POLICY` now applies to clone mode only; new rules `GENERATION_SAFE_ASSETS`, `NO_REAL_ASSET_IN_GENERATION` (any string naming one of the 457 registered files) and `NO_REAL_ENTITY_NAMES_IN_GENERATION` (denylist, whole-word, content and media strings, link/slug fields exempt). Allowlist gains `pageSpecProperties`, `modes`, `defaultMode`, `generationSafeAssetRoles`, `cloneOnlyAssetRoles`.
- verify_all pins the 12 compliance-critical roles to clone-only (a flip to the other, still-valid contract is caught), checks substitutes, generationRoles, the schema mode branch, default-mode agreement and denylist coverage of every named logo/author file.

**D. Raw style values replaced by token references.** Enumerating every section contract found 17 style-bearing fields in 11 sections, not just the two cited (`product.protein-visual` `bg` "#3cab57" and `product.use-cases` `hover` "rgba(60,171,87,0.4) 0px 0px 8px 0px"): modality colours (protein-visual, modalities-grid, use-cases), glows (use-cases), dot and label gradients (teams-cards-platform), logo size presets (hero.academia), padding presets (feature-rows), radius/gap/title type (sharing-is-caring), title colour (latest-updates), feature column and tile height presets (pipeline-benefits), testimonial slide gradients (proof.customers) and CTA screen positions (footer-cta-blue). Each is now a closed `{"token": id}` object whose schema enum is exactly the catalog ids matching its prefixes. New tokens backing them, all cited in measured-values.json: 4 foundation glows in elevation.json and 31 component presets in component.json. `product.pipeline-benefits` `featureCls`/`tileHPhone` were also wrong as required strings (the source treats them as an optional array and an optional value) and are now optional token refs. Validator rules `TOKEN_REFS_RESOLVE` and `NO_RAW_STYLE_LITERALS`; graph.json gains all 5 new rules (20 total), each implemented by the validator (checked).

**Adversarial suite** (now 566 checks): generation and clone controls for every template; every raw literal in every style field rejected by both schema and validator; raw hex, rgba shadow, px, easing, duration, gradient and Tailwind classes smuggled into copy or briefs; token ids not in the catalog, of the wrong category, of a non-referenceable category, outside the field prefixes, and in `$token`/alias/extra-key forms; every clone-only role in generation mode (mode absent and explicit); assetRef and content strings naming registered Cradle files; every denylisted customer, author and brand name in a testimonial attribution; plus controls (fictional attribution, whole-word near misses, link paths, clone mode reproducing real customers, another catalog colour).

**Drift proof** is now a script (`extraction/prove_drift.py`, 28 cases) instead of a manual note: allowlist parity, citation registration / range / anchor, manifest counts, `../` entry points, absolute paths, catalog staleness, policy category names, pinned asset contracts, default mode, denylist coverage, open motion schema, removed generation branch, example regressions, graph/validator rule mismatch and five disabled validator rules (template node-list cross-check, token refs, generation assets, name denylist, raw literals).

Not fixed (recorded): a few harvested contracts type geometry props as free strings (`hero.case`, `conversion.form-placeholder`, `content.doc-viewer`); the raw-literal rule now rejects unit-bearing values in them.

## 1.0.0 (2026-10-12)

Initial build from the local clone. 98 sections, 26 templates, 101 routes, 15 graph rules, 15 asset roles covering 457 registered files.

Verification performed (see README for how to re-run):
- Draft-07 `check_schema` and bundled example: 0 errors.
- `schema/tests/adversarial_test.py`: every control passes, every mutation rejected. It caught two real validator defects during the build, both fixed: a crash on a spec with no `route`, and a protocol-relative link (`//host.tld`) that slipped past `NO_EXTERNAL_LINKS`.
- `extraction/verify_all.py` drift checks were each proven against a scratch copy (phantom allowlist entry, orphan contract, out-of-range citation, in-range citation with wrong anchor, wrong manifest count, graph/validator rule mismatch).
- Self-containment: copied to an isolated temp directory with no siblings and re-run.
